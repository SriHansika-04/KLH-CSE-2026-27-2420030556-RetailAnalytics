## Abstract
The project proposes a Retail Sales Analytics and Customer Intelligence Framework that transforms retail sales data into actionable business insights. The Superstore Sales Dataset is preprocessed using Python, NumPy, and Pandas, followed by EDA and statistical analysis using Matplotlib and Seaborn to identify sales, customer, product, and regional patterns. Machine learning models including Linear Regression, Decision Tree, Random Forest, XGBoost, and K-Means are applied for sales prediction and customer segmentation, with XGBoost as the primary model for sales prediction. The framework incorporates Customer Lifetime Value (CLV) Prediction using RFM-based features and Scenario-Based Business Analysis to evaluate the impact of variables such as discount and quantity on predicted sales. MySQL is used for data storage, while Power BI provides interactive dashboards for sales, customer, product, regional, CLV, and scenario-based insights.

## Setup and Execution Instructions
1. Install Python and the required libraries.
2. Install Jupyter Notebook or VS Code.
3. Install MySQL and MySQL Workbench.
4. Install Power BI Desktop.
5. Run the Python source files/notebooks from the `/src` folder.
6. Connect the processed data to MySQL and Power BI for analysis and visualization.
